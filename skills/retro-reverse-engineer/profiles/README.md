# Profielstarters

Hierdie lêers bevat ondersoekvrae en afgebakende projekfeite, nie vooraf geverifieerde hardewarekonfigurasies nie.

- [C64](c64.md): oorspronklike Commando-platform as ondersoekstarter.
- [ZX Spectrum](zx-spectrum.md): toets oordraagbaarheid sonder C64-aannames.
- [Amiga](amiga.md): ander geheue-, grafika- en oudiomodel.
- [Ander platforms](other-platforms.md): model/variant vóór tegniese aannames.
- [Commando-spelprofiel](commando-game.md): plaaslike dokumentbasis en oop besluite.

Kopieer die [algemene platformprofiel](../templates/platform-profile.md) na 'n nuwe projekrekord en vul dit met werklike bewyse. Moenie die starter self as goedgekeurde projekkonfigurasie behandel nie.
